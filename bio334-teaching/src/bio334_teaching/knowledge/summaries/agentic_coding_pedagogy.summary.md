# Agentic Coding Pedagogy (Summary)

## Three-Layer Model
1. **Conceptual Understanding**: Can you explain what is being computed?
2. **Instruction Ability**: Can you give precise instructions to AI?
3. **Implementation Literacy**: Can you read and verify the code?

## Scaffolding Phases
- Phase 1 (Guided): Explain -> skeleton -> fill-in-the-blank
- Phase 2 (Partial): Problem presented -> student prompts AI -> verify
- Phase 3 (Autonomous): Problem only -> student decomposes and solves with AI

## Assessment Methods
- **Explain-Back**: Student explains concept in own words
- **Predict-Before-Run**: Predict output before executing code
- **Debug Challenge**: Find intentional bug in code

## Essential Skills to Preserve
1. Problem decomposition
2. Understanding abstraction (functions, modules, pipelines)
3. Tracing data flow (input -> processing -> output)
4. Critical verification ("Is this actually correct?")
5. Biological interpretation

## Common Anti-Patterns
- Forcing syntax memorization
- Making code-from-scratch the goal
- Banning AI use outright
- Running code without conceptual understanding
